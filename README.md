**Yoump Pioneer DJ Mixer** — это профессиональный системный DJ-микшер для Windows 11, выполненный в архитектуре клубных пультов **Pioneer DJM-2000 Nexus / DJM-900NXS2** и **Serato DJ Pro**. 

Проект объединяет нативный **C++20 Audio Processing Object (`Yoump.APO.dll`)**, работающий непосредственно внутри системного аудиографа Windows (`audiodg.exe`) с нулевой задержкой, студийный процессор микрофона с **Zero-Latency ИК-свёрткой (метод Гарднера)**, аппаратный интерфейс на **Direct3D 11 / Direct2D 1.1** (до $240\text{ FPS}$) и нативную 14-битную интеграцию с DJ-контроллером **Pioneer DDJ-SB3**.

## Ключевые возможности

### 1. Системный движок C++20 APO и DSP (`Yoump.APO` + `Yoump.DSP`)
* **Обработка внутри `audiodg.exe` (Stream Effect / SFX):** каждое открытое приложение Windows (браузеры, плееры, игры, мессенджеры) получает собственный независимый экземпляр DSP-процессора в реальном времени (до 64 одновременных потоков, $32\text{-bit IEEE Float}$, частота дискретизации от $8\text{ kHz}$ до $384\text{ kHz}$).
* **Неблокирующий обмен через Shared Memory (`Local\YoumpDspSharedMemV4`):** синхронизация параметров между UI и `audiodg.exe` осуществляется через общую страницу памяти с протоколом `SeqLock`, атомарными барьерами и автоматическим сторожевым таймером (`Heartbeat` / `Fail-Safe Bypass` при закрытии приложения).
* **Интеллектуальный матчинг потоков:** автоматическое сопоставление аппаратных слотов APO с процессами Windows с учётом нелинейного усиления полос эквалайзера, `Trim` и фильтров.

### 2. Канальная линейка Pioneer DJM-2000 Nexus / DJM-900NXS2
Каждая программа Windows и микрофонный вход выводятся на отдельную вертикальную деку микшера:
* **TRIM:** нелинейный входной регулятор чувствительности от $-\infty\text{ dB}$ до $+9\text{ dB}$ с центральной фиксацией $0.0\text{ dB}$.
* **3-Band Linkwitz-Riley 4th Order ($\text{LR4}$) Isolator EQ:**
  * Фазово-согласованный кроссовер 4-го порядка ($24\text{ dB/oct}$) с частотами раздела $f_{\text{low}} = 250\text{ Hz}$ и $f_{\text{high}} = 3500\text{ Hz}$ и фазовыравнивающим фильтром `All-Pass`.
  * Режим **Total Kill** (полное выключение полосы при $\le -11.7\text{ dB}$) и плавный подъём до $+6.0\text{ dB}$ без фазовых искажений при суммировании полос.
* **4 режима блока Sound Color FX:**
  1. **`FILTER (LPF / HPF)`** — сдвоенный каскадный фильтр `Cytomic State Variable Filter (SVF)` с моделированием фирменного резонансного пика Pioneer ($Q = 1.45$).
  2. **`SPACE (DUB ECHO / STEREO SPACE)`** — честная архитектура *Send / Return* с интерполированной линией задержки ($240\text{ ms}$ LPF Dub Echo влево / $165\text{ ms}$ HPF Space Echo вправо) и кросс-канальной стереосвёрткой ревербератора с естественным затуханием хвоста после возврата ручки в `BYPASS`.
  3. **`CRUSH (DRIVE / BITCRUSHER)`** — тёплое гиперболическое насыщение $\tanh$ при повороте влево и жёсткое квантование с децимацией частоты дискретизации при повороте вправо.
  4. **`LOUD (VOCAL FOCUS / SUB+AIR)`** — выделение вокальной середины с ослаблением саб-баса влево или динамический эксайтер субгармоник и «воздуха» вправо.
* **Pioneer Soft-Knee Limiter:** прозрачный мастер-лимитер с мягким коленом (порог $0.80$, гиперболическое сжатие пиков до $0\text{ dBFS}$).

### 3. Студийный тракт микрофона (`MAIN MIC`) и Zero-Latency IR Convolution
* **Умный селектор входов `XLR 1 / XLR 2`:**
  * Режим **Auto-Latch** автоматически определяет активный микрофонный вход звуковой карты (`Roland QUAD-CAPTURE` / `UA-55`) и подавляет шум неиспользуемого преампа, распределяя голос строго в центр стереобазы.
  * Доступно ручное переключение: `XLR 1 Only (L)`, `XLR 2 Only (R)`, `Dual Mono (XLR 1 + XLR 2)`.
* **Вокальный процессор реального времени:**
  * Обрезной фильтр взрывных согласных $80\text{ Hz}$ Anti-Pop ($12\text{ dB/oct}$ или $24\text{ dB/oct}$ $\text{LR4}$).
  * Экспандер / Noise Gate с гистерезисом открытия и закрытия.
  * Динамический **De-Esser** на частоте сибилянтов $6500\text{ Hz}$.
  * Вокальный компрессор с мягким коленом и автоматическим Make-Up Gain.
  * Блок **Anti-Feedback**: инверсия фазы $180^\circ$ и пара узкополосных режекторных фильтров ($2150\text{ Hz}$ и $3850\text{ Hz}$, $Q = 6.5$).
  * **Talkover (Ducking):** автоматическое приглушение музыки при речи в микрофон (`STANDARD` $-14\text{ dB}$ или `ADVANCED` Mid-Band Ducking $-9.5\text{ dB}$ только в среднечастотном диапазоне музыки).
* **Свёртка с нулевой задержкой (Gardner Partitioned Convolution):**
  * Гибридный конвольвер (прямой FIR-заголовок на 64 отсчёта + 15 секций частотной линии задержки FDL по 128 точек БПФ).
  * **6 встроенных импульсных моделей:** `Shure SM7B`, `Neumann U87 Ai`, `Electro-Voice RE20`, `Sony C800G`, `Lexicon 480L Vocal Plate`, `Pioneer DJM Club Space` + загрузка собственных `.wav` импульсов с автоматическим ресемплингом.

### 4. Графический движок Direct3D 11 + Direct2D 1.1 (`Vortice.DirectX`)
* Аппаратный рендеринг через `IDXGISwapChain1` (`FlipSequential`) с поддержкой частоты обновления от $15$ до $240\text{ FPS}$.
* **Живые 3-полосные волны Serato / Rekordbox RGB:** спектральное разделение баса, середины и высоких частот в реальном времени с визуализацией влияния ручек `EQ`, `Trim`, `Fader` и шейдеров `ColorFX` (`Echo`, `Drive`, `Crush`).
* Поддержка Mip-Map кэша форм волны `.wpk` через Memory-Mapped Files.
* 15-сегментные индикаторы уровня с удержанием пиков (`Peak Hold`), информационный дисплей секции `MASTER` (OSD) и сворачивание в системный трей.

### 5. Аппаратная интеграция с Pioneer DDJ-SB3 и защита Bluetooth LDAC
* **Pioneer DDJ-SB3 (14-bit MIDI):** автоматическое обнаружение контроллера, отправка пробуждающего SysEx-пакета Serato (`F0 00 20 7F 03 01 F7`), считывание 14-битных регуляторов (`MSB + LSB`), переключение режимов `ColorFX`, `MUTE`, `SOLO` и быстрый сброс параметров с удержанием `SHIFT`.
* **Автоматическая маршрутизация Windows Audio Policy:** перенаправление звучащих приложений на основной выход `1-2 (QUAD-CAPTURE)` или Bluetooth Hi-Res наушники через недокументированные COM-интерфейсы `AudioPolicyConfig` и `IPolicyConfig`.
* **LDAC Guard:** защита от деградации звука Bluetooth-наушников (блокирует переключение профиля A2DP / LDAC $96\text{ kHz}$ в монофонический гарнитурный режим `Hands-Free AG / HFP` $16\text{ kHz}$, автоматически оставляя активным студийный микрофон звуковой карты).
* **Режим ASIO:** поддержка прямого низколатентного ввода/вывода через драйвер `ASIO` (`Roland QUAD-CAPTURE`) с вызовом аппаратной панели управления.

## Требования и сборка

### Системные требования
* **ОС:** Windows 10 / Windows 11 ($64\text{-bit}$).
* **Среда разработки:** Visual Studio 2022 / 2026 с установленными компонентами:
  * *Разработка классических приложений на C++* (MSVC `v143` / `v145`, Windows 10/11 SDK).
  * *.NET SDK 10.0* (`net10.0-windows`).

### Порядок сборки
1. **Сборка нативных модулей C++ (`Yoump.DSP.dll` и `Yoump.APO.dll`):**
   Откройте проекты `Yoump.DSP.vcxproj` и `Yoump.APO.vcxproj` в конфигурации `Release | x64` и выполните сборку:
   ```powershell
   msbuild Yoump.DSP\Yoump.DSP.vcxproj /p:Configuration=Release /p:Platform=x64
   msbuild Yoump.APO\Yoump.APO.vcxproj /p:Configuration=Release /p:Platform=x64
   ```
   Скомпилированные библиотеки будут помещены в каталог `build\`.

2. **Сборка основного приложения (`yoump_mixer_win11.exe`):**
   Соберите проект `YoumpMixerWin11.vbproj` (таргет `CopyNativeCppDlls` автоматически скопирует `Yoump.DSP.dll` и `Yoump.APO.dll` из папки `build\` в выходной каталог):
   ```powershell
   dotnet build YoumpMixerWin11.vbproj -c Release
   ```

## Установка системного C++ APO и управление

### Регистрация Kernel APO в Windows 11
Для того чтобы эквалайзер, `Trim` и эффекты `ColorFX` обрабатывали звук каждого отдельного приложения прямо внутри ядра аудиоподсистемы Windows (`audiodg.exe`), а студийная обработка микрофона работала глобально во всех программах (Discord, Telegram, OBS, браузеры):
1. Запустите `yoump_mixer_win11.exe`.
2. Нажмите правой кнопкой мыши на свободном месте микшера и выберите **«Зарегистрировать C++ APO на 1-2 (QUAD-CAPTURE) [Админ]»** (либо нажмите кнопку установки на вкладке **«2. Микрофон / IR»** в окне настроек).
3. Подтвердите запрос прав Администратора (UAC). Скрипт автоматически скопирует `Yoump.APO.dll` и `Yoump.DSP.dll` в `System32`, настроит права доступа `LPAC` для `C:\ProgramData\Yoump`, зарегистрирует `SFX APO` на целевых устройствах воспроизведения/записи и перезапустит службу `Audiosrv`.

## Управление мышью и контроллером Pioneer DDJ-SB3

| Элемент управления | Действие мыши в UI | Контроллер Pioneer DDJ-SB3 |
| :--- | :--- | :--- |
| **Поворот ручек и фейдеров** | Зажать `ЛКМ` и тянуть вверх / вниз | Аппаратные ручки `TRIM`, `HI`, `MID`, `LOW`, `FILTER`, фейдеры дек |
| **Сброс регулятора в центр ($0\text{ dB}$)** | `ПКМ` по любой ручке или фейдеру | `SHIFT + LOAD` (или `SHIFT + CUE`) |
| **Выбор режима Color FX** | `ЛКМ` по кнопке `FX: FILTER` над ручкой | Кнопки `FX 1-1` / `FX 1-2` / `FX 1-3` |
| **MUTE / SOLO канала** | `ЛКМ` по кнопкам `MUTE` и `SOLO` | Кнопка `CUE` (`MUTE`), `SHIFT + CUE` (`SOLO`) |
| **Масштабирование волны (`Zoom`)** | Колесо мыши над экраном волны канала | Индивидуально для каждого канала ($25\% \dots 400\%$) |
| **Прокрутка микшера по горизонтали** | Колесо мыши в зоне эквалайзера/фейдеров | Автоматическое расширение окна под число активных программ |
| **Контекстное меню и настройки** | `ПКМ` на свободном фоне микшера или иконке в трее | Быстрый выбор пресетов EQ, ИК-импульсов, режимов Talkover и выхода |
